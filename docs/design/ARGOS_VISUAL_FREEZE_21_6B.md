## Visual identity

Preserve:

- ivory institutional surface
- graphite/dark structural contrast
- canonical navy authority
- restrained teal/mineral system accent
- Cormorant Garamond display only
- Inter body/UI
- generous negative space
- controlled asymmetry
- institutional editorial hierarchy
- premium without luxury excess
- technologically precise but human

Canonical palette remains:

| Role | Hex |
|------|-----|
| Primary | `#1F3A5F` |
| Secondary | `#2F7D6D` |
| Surface | `#F7F7F5` |
| Dark | `#0B1320` |

No near-equivalent substitutions.

## ARGOS Perimeter System

```
ARGOS_PERIMETER_SYSTEM = APPROVED
```

The proprietary visual grammar is:

- perimeter
- observation
- signal
- continuity
- controlled infrastructure

It must remain:

- quiet
- architectural
- precise
- intelligent
- subtle

It must **NOT** become:

- HUD
- dashboard
- cybersecurity cliché
- shield
- lock
- neon network
- AI gradient
- floating SaaS cards
- circuit-board decoration

The motif may echo subtly through later sections.

It must not dominate every section.
