3. Enrollment / Heartbeat / Observaciones

Enrollment NOC crea token TTL → agent POST enroll → consume atómico → credencial operativa → primer heartbeat.
Heartbeat Intervalo + jitter · seq anti-replay · server_received_at manda para STALE/OFFLINE.
Observations Tipadas + schema + capability · idempotency_key · proyectan a healthEngine (una verdad).
