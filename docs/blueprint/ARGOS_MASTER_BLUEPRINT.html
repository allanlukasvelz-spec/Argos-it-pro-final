Si A falla, ARGOS aprende

A FAIL → failure evidence → reduce hipótesis → Action B (predeclarada)
B FAIL → Action C
C FAIL → SAFE STOP / ROLLBACK / ESCALATE

Journeys

  6. DB failure → diagnóstico → recovery
