## Model

```
TECHNICAL CONTROL → EVIDENCE → ASSESSMENT → CONTROL MAPPING → FRAMEWORK → REPORT
```

ARGOS may produce **evidence packs**. ARGOS does **not** claim ISO/SOC certification.

- CIS Controls

## Separation

| ARGOS EVIDENCE | FORMAL CERTIFICATION |
|----------------|----------------------|
| Technical artifacts, timestamps, hashes | Auditor / accredited body |
| Control mapping assistance | Legal attestation |
